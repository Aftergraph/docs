## Glossary

| Term | Meaning |
|---|---|
| **Knowledge Plane** | This portal: a compiler/rendering/discovery layer over canonical sources. Owns no truth. |
| **Canonical source** | The owning repository at a pinned full SHA — the only authority for its content. |
| **Provenance** | Page-level binding to owner repo@commit + semantic version + evidence cut. |
| **Four clocks** | Source truth (commit), semantic truth (spec version), evidence truth (cut), live truth (remote state). |
| **Freshness status** | `CURRENT` / `SOURCE_MOVED_CONTENT_UNCHANGED` / `SOURCE_MOVED_CONTENT_CHANGED` / `STALE` / `UNKNOWN` — ADR-004 policy. |
| **Evidence class** | Deterministic, methodological-pilot, live_valid, synthesis — never interchangeable. |
| **Evidence cut** | The audit/date snapshot a claim's evidence was taken at (e.g. `AUDIT-EVID-001 2026-09-04`). |
| **Context pack** | ACC-shaped portable JSON bundle per page: owner, source commit, dependency contracts, related claims, next reading. |
| **Adoption** | Explicit, reviewable pin update via `adopt-source.mjs`. Never automatic. |
| **Private leakage** | Any private-repo reference in public build output — structurally blocked by allowlist + scan gates. |

Canonical terminology beyond this table lives in
[`after-graph-governance`](https://github.com/Aftergraph/after-graph-governance).

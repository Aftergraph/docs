## Interoperability position

Aftergraph composes existing standards where they solve a problem (RFC 8693
for exchange envelopes, RFC 3161/Rekor for anchoring) and invents only the
layer the industry is missing: institution semantics for autonomous agents.
Nothing here is declared stable before external blind reproduction —
see [C-005](/evidence/claim-graph/) for the current honest state.

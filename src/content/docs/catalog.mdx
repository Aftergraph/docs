## Entity classes

The catalog schema supports: Repository, System, Product, Specification,
Contract, API, Schema, ResearchProgram, Paper, Study, Experiment, Benchmark,
EvidenceArtifact, Model, Skill. Repos are populated first; the remaining
classes fill as owning repos publish machine-readable metadata.

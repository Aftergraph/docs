## Run it locally

Same commands the quickstart verifies:

```bash
git clone https://github.com/Aftergraph/docs.git
cd docs && npm ci
npm run build                              # 9 gates (page count grows; see sidebar)
node scripts/freshness.mjs                 # pins vs live remote state
```

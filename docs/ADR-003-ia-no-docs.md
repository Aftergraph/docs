# ADR-003 — IA without a generic "Docs" section

Governance `PUBLIC-INFO-ARCHITECTURE-v0.1` (provisional planning artifact)
lists a `Docs` top-level. The mission IA overrides it: Platform, Developers,
Research, Standards, Evidence, Catalog, Company. Rationale: a generic Docs
section duplicates every other section and hides canonical ownership.
Developer modes follow Tutorials / How-to Guides / Reference / Explanation.

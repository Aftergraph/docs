# ADR-001 — Portal placement: `Aftergraph/docs`

Ownership audit 2026-09-06 (fresh `gh repo list Aftergraph`, 16 repos): no
existing repo owns the knowledge-plane role; `docs` and `developer-portal`
both absent. Decision: create **`Aftergraph/docs`** (preferred per mission),
public. Alternative `developer-portal` rejected to keep the canonical,
predictable name. The repo owns no specs/claims/contracts — compiler only.
